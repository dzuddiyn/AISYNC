# CrossAI Sync — Product Branding

**Status:** LOCKED  
**Date:** 2026-10-06  
**Owner:** Project Owner  
**Scope:** Product naming and user-facing terminology only

## Locked naming hierarchy

| Layer | Locked name | Usage |
|---|---|---|
| Product / official brand | **CrossAI Sync** | Public product name, web UI, onboarding, release-facing material |
| Ordinary user shorthand | **CrossAI** | Natural conversational shorthand for users |
| Engine / internal architecture | **AISYNC** | Repository, architecture, engineering documentation, internal system identity |
| Internal engineering short-form | **ASC** | Runtime/contracts/components/internal technical shorthand |

## Product rule

User-facing surfaces should prefer:

```text
CrossAI Sync
```

or, where a shorter conversational label is appropriate:

```text
CrossAI
```

Ordinary users should not need to understand `AISYNC` or `ASC` to use the product.

Technical/advanced surfaces may expose the internal relationship factually:

```text
CrossAI Sync
      ↓
AISYNC engine / architecture
      ↓
ASC runtime / contracts / internal components
```

## Repository and architecture continuity

This branding decision does **not** rename the `dzuddiyn/AISYNC` repository and does not alter confirmed AISYNC architecture, contracts, authority boundaries, or persistence semantics.

`AISYNC` remains the engineering/system identity.

`ASC` remains valid internal shorthand used throughout existing technical artifacts.

## UI direction

The future polished web UI should present **CrossAI Sync** as the primary brand.

Recommended product hierarchy:

```text
CrossAI Sync
One project. Any AI. Keep moving.
```

The tagline above is a presentation candidate, not a separate locked semantic contract.

Internal labels such as AISYNC/ASC may remain available in Review, diagnostics, developer documentation, or advanced technical views where they are useful.

## Naming invariant

```text
CrossAI Sync = product
CrossAI      = user shorthand
AISYNC       = engine / architecture
ASC          = internal engineering shorthand
```

Do not collapse these layers into one name unless the Project Owner explicitly revises this branding decision.
